# SDA Group Project

This folder contains the code for our SDA group project.

## Overview
This project is a software design architecture assignment created as part of a group effort. The code in this folder is the main implementation of the project.

## How to Use
1. Open the project folder in your code editor.
2. Install any required dependencies before running the code.
3. run renderingContext.py
4. use the button shown on the checkpoints to move the robot to the corresponding checkpoint

## Dependencies
- pygame CMD: ``pip install pygame``
- math CMD: ``pip install math``
- random CMD: ``pip install random``
